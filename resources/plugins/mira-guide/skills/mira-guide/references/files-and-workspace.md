# 文件与工作区

## 浏览与搜索

- 从项目菜单打开项目文件；多源项目可分别打开各源文件夹。
- 文件树单击文件打开预览，目录可展开；右键可打开、用外部编辑器打开、在 Finder/资源管理器显示、复制路径或加入对话。
- 文件面板顶部 **搜索文件** 会对当前工作区建立索引并按名称和路径模糊匹配。匹配超过上限时只显示前 1000 项。
- 符号链接只有在真实目标仍位于授权工作区内时才会显示或读取；越界链接被拒绝。

## 搜索忽略规则

入口：**设置 → 文件搜索**。

1. 选择项目或个人工作区。
2. 编辑“搜索忽略规则”；规则保存在该工作区的 `.miraignore`。
3. 可用 **从 .gitignore 同步** 或 **恢复默认规则**，确认后点击 **保存**。

`.miraignore` 使用 `.gitignore` 语法，只影响文件搜索，不隐藏文件树，也不限制 Agent 的文件访问。首次搜索可能根据 `.gitignore` 和默认排除项生成规则；之后 `.gitignore` 的变化不会自动同步。规则必须是 UTF-8 文本且不超过 256 KiB。

## 预览能力

- 文本、代码、Markdown 和 SVG：读取为文本；普通文本预览上限为 1 MB，二进制内容不会按文本预览。
- 常见位图：APNG、AVIF、BMP、GIF、ICO、JPEG、PNG、WebP；单张预览上限 4 MiB。
- PDF、Word、表格、演示文稿、音视频：使用各自的专用阅读或播放视图；具体格式仍取决于媒体识别和本机解码能力。
- Markdown 与 SVG 可在“预览/源码”之间切换；文本可切换自动换行并复制内容。

“无法预览”不一定表示文件不能被 Agent 使用。先区分是预览格式、大小、权限、文件损坏还是工作区越界。

## 加入对话

在文件树右键文件选择 **加入对话**，或在文件预览工具栏点击“将当前文件加入对话”。目录只能从输入区的“添加文件或文件夹”选择。

当前支持作为二进制模型附件的类型是：

- 图片：PNG、JPEG、GIF、WebP。
- 文档与视频：PDF、MP4、M4V、MOV、WebM、MKV、AVI。

Office 文档可以在预览中阅读，但不能直接作为模型附件；音频可以播放，但当前不作为模型附件。其他位图应先转换为 PNG、JPEG、GIF 或 WebP。

附件前置限制：一次最多 12 个文件；单个图片/PDF/视频 20 MiB，合计 40 MiB；通过文件选择器读取的单个文本 256 KiB，内联文本合计 1 MiB。最终能否送入模型还取决于所选模型是否声明对应图片、PDF 或视频输入能力。

## 工作区边界

- 项目任务默认文件工具和命令工作目录是项目主要目录。
- 项目文件浏览可以切换到其他源文件夹；这不改变任务默认工作目录。
- 个人任务使用 Mira 的个人工作区；普通相对文件引用不能逃出该目录。
- 所有读取都会重新检查真实路径，拒绝 `..` 越界和指向工作区外的符号链接。
- 已归档任务不能继续添加附件；目录或文件在读取期间变化时需要刷新后重试。

## 文件无法预览或加入对话时

1. 确认项目目录仍存在，并在文件面板点击 **刷新文件**。
2. 查看错误是否为“文件过大”“二进制”“格式不支持”或“没有权限”。
3. 若预览可用但“加入对话”灰色，查看按钮提示：Office、音频和部分图片格式只支持预览。
4. 对 PDF/视频/图片，切换到声明相应输入能力的模型。
5. 检查附件数量与大小；移除部分附件后重试。
6. 若搜索不到但文件树可见，进入 **设置 → 文件搜索** 检查 `.miraignore`。
