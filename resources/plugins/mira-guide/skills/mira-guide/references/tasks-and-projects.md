# 任务与项目

## 入口

- 左侧栏顶部 **新建任务**：创建一个未发送的任务草稿。
- 左侧栏 **项目** 标题右侧的 **添加项目**：打开“创建项目”。
- 项目菜单中的 **新建任务**：直接在该项目中创建任务。
- 左侧栏 **个人工作区**：查看或新建不属于项目的任务。

## 创建项目

1. 在左侧栏“项目”区域点击 **添加项目**。
2. 填写“项目名称”。
3. 在“源文件夹”中点击 **选择文件夹**；需要多个目录时继续点 **添加文件夹**。
4. 多个源文件夹中选择一个 **设为主要**。至少保留一个源文件夹，主要目录必须属于源文件夹列表。
5. 点击 **创建项目**。
6. 在“信任此文件夹吗？”或“信任这些文件夹吗？”中核对每条绝对路径，再点 **信任文件夹并创建**。

信任确认表示 Mira 可以在当前权限设置允许的范围内读取、编辑列出的文件夹并运行命令。不要信任来源不明的目录。

主要目录是项目任务的默认工作目录，也是命令和 Agent 文件工具的默认边界。其他源文件夹会作为项目文件来源显示，可用于浏览和引用，但不会把任务默认工作目录改成这些目录。

## 项目任务与个人任务

| 项目任务 | 个人任务 |
| --- | --- |
| 绑定一个项目，默认工作目录为项目主要目录 | 不属于项目，使用 Mira 管理的个人工作区 |
| 可使用项目文件、项目级命令、Agent、MCP、Hook 和项目记忆 | 不具有项目级配置，适合通用问答或临时任务 |
| 可在同一项目下引用其他任务；用 `#` 也可引用其他项目任务 | `#` 可引用本地其他任务 |
| 项目目录不可用时仍可查看历史，但不能正常使用工作区能力 | 只能在个人工作区边界内使用文件工具 |

未发送的任务草稿可以切换项目或回到个人工作区。任务一旦已发送，就不能通过草稿切换把它迁移到个人工作区。

## 编辑多源项目

从项目菜单进入 **编辑项目**，可以改名、添加或移除源文件夹、切换主要目录。新增目录必须存在；主要目录不能与另一个项目的主要目录重复。项目仍有运行中的任务时，先停止运行再保存项目变更。

移除项目与删除磁盘文件不是一回事，但项目删除会同时删除该项目在 Mira 中的任务记录；执行前应确认影响。插件的“移除”另有不同语义，见插件章节。

## 任务能力快照

- 插件能力目录在任务首次实际运行时固定身份。任务草稿尚未首次运行时，会在首次运行取得当时的目录。
- 后来安装或启用的新插件不会自动加入已经固定目录的任务；新建任务最稳妥。
- 当前任务仍会实时检查插件是否启用、来源目录是否相同、能力是否仍存在。停用、移除或修改声明可能使旧任务里的能力变为不可用。
- Skill、MCP 等会话选择是另一层状态。插件属于任务目录，不代表 MCP 已在该会话选中或已连接。
- 新任务默认权限来自 **设置 → 对话设置 → 权限**；已有任务保留自己的权限模式。

## 常见限制

- “项目目录不可用”：恢复原路径，或编辑项目选择有效目录；历史任务仍可查看。
- “主要目录不可用”：确认目录存在且为文件夹，并且没有被其他项目占用。
- “至少保留一个源文件夹”：先添加替代目录，再移除旧目录。
- 信任弹窗列出多个目录时必须逐项核对；其中任一目录不可信就取消。
