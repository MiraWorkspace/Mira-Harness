# 故障排查

先记录用户看到的准确文案、当前任务是否运行、任务所属项目、所选模型、权限模式，以及插件/MCP/Hook 的状态。不要用“重启试试”替代状态检查。

| 现象 | 常见原因 | 检查入口 | 处理步骤 |
| --- | --- | --- | --- |
| 无法创建项目 | 未选择目录、主要目录不在源文件夹中、目录不存在或已被其他项目占用 | 左侧栏 **项目 → 添加项目** | 至少选择一个真实目录；将其中一个设为主要；核对信任弹窗中的全部路径后创建 |
| 项目历史能看但文件不可用 | 项目主要目录已移动、离线或无权限 | 项目菜单 **编辑项目** | 恢复原路径或选择有效目录；停止正在运行的项目任务后保存 |
| 当前任务看不到刚安装的插件 | 插件未启用，或当前任务的插件能力目录已固定 | **插件市场 → 本地** | 确认已启用且无错误；新建任务再试。尚未首次运行的草稿会在首次运行取得当前目录 |
| 引用插件后仍无可用 Skill | 插件不含 Skill、同名冲突、Skill 已改名/移除，或插件被停用 | 插件详情与输入区 `@` | 查看插件组件列表和错误；停用重名插件；内容变化后新建任务 |
| MCP 安装了仍不能用 | 只安装/启用了服务，没有进入当前会话选择；连接或授权失败 | 输入区 `/` → **MCP 服务** | 选中服务；等待任务启动连接；按状态完成授权或重连。运行中先停止/等待结束 |
| MCP 显示“任务启动时连接” | 插件/项目 MCP 已声明但当前尚未启动连接 | 输入区 `/` → **MCP 服务** | 保持当前会话已选，发送下一条任务；失败时检查插件、项目配置、命令、网络和授权 |
| Hook 要求重新信任 | Hook 的命令、参数、来源、插件声明或修订变化 | **设置 → 事件钩子（Hooks）** | 重新核对事件、命令、参数和来源；确认可信后“审阅并授权”。不要复制旧信任记录 |
| “自动审核/完全访问”不可选 | 设置页未允许该权限档位 | **设置 → 对话设置 → 权限** | 打开对应“允许选择”开关，再回任务选择；已有任务的当前模式不会被默认值自动改写 |
| 推理强度不显示或不可用 | 所选模型未声明推理能力，或模型配置不可用 | 输入区模型菜单；**设置 → 模型服务** | 切换支持推理的已启用模型；再选关闭/低/中/高 |
| 计划模式下能力不可用 | Agent、工作流、插件 Skill 或动态命令受计划模式限制 | 输入区 **计划模式** | 先提交并确认计划，或关闭计划模式后重新选择能力 |
| 文件搜索不到但文件树能看到 | `.miraignore` 排除了该路径；搜索缓存未刷新 | **设置 → 文件搜索**；文件面板 **刷新文件** | 检查规则；必要时从 `.gitignore` 同步或修改并保存；回文件面板刷新 |
| 文件无法预览 | 超过预览大小、二进制/格式不支持、无权限、文件变化或越界链接 | 项目文件预览 | 读错误文案；转换格式/减小文件；刷新；确认真实文件在授权根内；必要时用外部编辑器 |
| “加入对话”按钮灰色 | Office/音频只支持预览、图片格式不支持、文件删除，或预览尚未完成 | 文件预览按钮提示 | Office 内容改为支持的文本/PDF，音频当前不能附加；图片转 PNG/JPEG/GIF/WebP；刷新后再试 |
| 附件发送失败 | 超过 12 个、单文件或总大小超限，或模型不支持图片/PDF/视频 | 输入区附件与模型选择器 | 移除/压缩附件；切换声明对应输入能力的模型；不要只依据本地预览成功判断模型支持 |
| 自动化不运行 | 已暂停/结束、时间或有效期错误、电脑休眠、应用/网络/模型不可用 | **自动化** 任务卡与运行历史 | 查看下次运行和失败记录；恢复任务；修正计划；保持电脑运行；检查模型服务 |
| 工作流入口不显示或不能启动 | 不是主项目会话、项目目录不可用、处于计划模式，或已有冲突状态 | 项目任务添加菜单或 `/`；**自动化 → 工作流** | 回到可用项目主任务，关闭计划模式，清除当前引用后重新创建；审阅源码和流程图后再确认 |

## 分层判断顺序

1. **登记层**：插件、模型、项目或自动化是否存在。
2. **启用层**：插件、Skill、MCP、模型、Hook 或任务是否已启用。
3. **任务层**：能力是否属于当前任务快照，项目和工作目录是否仍一致。
4. **会话层**：MCP/Skill 是否在当前会话选择，任务是否正在运行而锁定配置。
5. **连接与信任层**：MCP 是否连接/授权，Hook 是否信任当前修订。
6. **执行层**：普通权限审批、模型输入能力、网络、命令环境和文件大小是否满足。

如果某层失败，先修复该层再重试；不要通过提高到“完全访问”来掩盖来源、路径、连接或格式问题。
