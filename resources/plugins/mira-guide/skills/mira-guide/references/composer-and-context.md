# 输入区、上下文与会话配置

## 输入区的四个触发符

- `@`：当前工作区的文件、文件夹、插件、Agent 和对话。对话候选默认限制在当前项目。
- `/`：Mira 命令、自定义命令、插件命令，也可进入 Skill、Agent 等能力选择。自定义命令和插件命令必须放在消息开头。
- `$`：选择已启用的 Skill。中文键盘输入 `¥` 或 `￥` 也会按 `$` 处理。
- `#`：搜索并引用本机任务；可以跨项目选择。

也可以点击输入区的添加菜单：**添加文件或文件夹**、**计划模式**、**命令与能力**、工作流等会根据当前任务状态显示。

选择候选时可用方向键移动，`Enter` 或 `Tab` 确认，`Escape` 关闭。

## 引用文件或其他任务

### 文件

1. 在输入区键入 `@文件名`，或点击添加菜单中的 **添加文件或文件夹**。
2. 从当前任务工作区选择文件或目录。
3. 发送前检查输入区中的引用项；引用在发送时读取并受当前工作区权限约束。

没有项目的匿名草稿需要先选择项目，才能从项目文件中引用。也可从“项目文件”右键菜单或预览工具栏选择 **加入对话**。

### 其他任务

1. 用 `@` 引用当前项目内的任务，或用 `#` 搜索本机其他任务。
2. 选择后，Mira 会把该任务可引用的用户与助手正文复制到当前草稿中。

这不是实时链接；原任务之后的更新不会自动同步。空任务、只有内部记录或没有可引用正文的任务会提示“此对话暂无可引用的内容”。

## 命令、Skill、Agent 与 MCP 在输入区的含义

- **命令**：在消息开头展开为一段已配置的任务指令；插件命令形如 `/插件名:命令名`。
- **Skill**：给当前 Agent 加载专项操作说明。`$` 是直接选择 Skill；`@插件` 是引用该插件并让 Agent 按需读取其中 Skill。
- **Agent**：引用后由主 Agent 按需委派，不代表一定立即运行。需要可用工作目录，且“子任务委派”已开启；计划模式下不可委派。
- **MCP**：向当前会话提供外部工具。安装或启用服务不等于当前会话已选择、连接或完成授权。

## 模型与推理强度

- 在输入区底部的模型选择器切换当前模型。
- 只有声明支持推理的模型才显示 **推理强度**；可选 **关闭、低、中、高**。
- 模型不可用时，前往 **设置 → 模型服务** 检查服务商是否启用、API 密钥、接口地址和模型是否启用。
- 图片、PDF、视频能否真正发送给模型，还取决于所选模型声明的输入能力。

## 权限模式

输入区可通过 **权限模式** 或 `/perm` 选择：

- **逐次确认**：每次执行需要向用户确认。
- **自动审核**：有风险时询问。
- **完全访问**：减少确认次数，风险最高。

“自动审核”和“完全访问”必须先在 **设置 → 对话设置 → 权限** 中允许选择。设置页的“新任务默认权限”只影响新任务；在输入区切换影响当前任务的后续提交。

权限模式不会绕过工作区路径、插件来源、Hook 信任、MCP 授权或其他宿主安全校验。

## 计划模式

在添加菜单或 `/` 面板选择 **计划模式**。该模式用于先澄清问题、读取必要信息并提交待确认方案；确认后再进入执行。计划模式与持续目标不能同时开启，且插件 Skill、需要 Skill 或 Shell 动态展开的命令、Agent 委派和工作流等能力可能不可用。遇到“请关闭计划模式后发送”时，先关闭计划模式再重新选择该能力。

## MCP 会话选择

1. 在 `/` 面板选择 **MCP 服务**。
2. 查看服务状态和来源，选中需要的服务；界面会标注“此会话已选/未选”。
3. 服务通常在任务启动时连接。OAuth 服务显示“等待授权”时，按提示到管理页面完成授权。
4. 当前任务运行中不能修改服务选择；先等待结束或停止运行。
5. 全局 MCP 连接失败时可在同一面板尝试 **重连**；插件或项目 MCP 需检查其插件/项目配置。

显式引用插件或调用插件命令时，宿主会把该插件已声明且可用的 MCP 加入当前会话，但仍要通过能力快照、启用状态、授权和普通权限校验。
